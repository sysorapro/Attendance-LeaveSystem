# تطبيق APK لنظام الحضور والانصراف (SYSORA)

التطبيق ده "غلاف" أندرويد (WebView) بيفتح نفس الـ Web App بتاعك، فبيشتغل على **نفس قاعدة البيانات (الشيت)** ونفس الصلاحيات والجلسات بدون أي تكرار للكود.

## 1) هات رابط الـ Web App
في Apps Script: **Deploy → Manage deployments** وانسخ الرابط اللي بينتهي بـ `/exec`.
(الإعداد الحالي `ANYONE_ANONYMOUS` مناسب، مفيش تغيير مطلوب.)

## 2) حط الرابط في التطبيق
افتح `app/src/main/res/values/strings.xml` وغيّر قيمة `web_app_url`.

## 3) ابني الـ APK (من غير Android Studio)
1. اعمل Repository جديد على GitHub وارفع محتويات المجلد ده.
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد دقيقتين حمّل `SYSORA-Attendance-APK` من Artifacts، وفك الضغط هتلاقي `app-debug.apk`.
4. انقله للموبايل وثبّته (فعّل "تثبيت من مصادر غير معروفة").

(بديل: افتح المجلد في Android Studio ← Build ← Build APK.)

## 4) تحديث ملفات النظام (مطلوب للبصمة وتصدير CSV)
روابط التحميل العادية مش بتشتغل جوه WebView. استبدل الملفات الأربعة `AppScript.html` و`Pages.html` و`AdminPages.html` و`LoginPage.html` في مشروع Apps Script بالنسخ الموجودة في `webapp_patch/`، وبعدها Deploy ← Manage deployments ← Edit ← Version: New version ← Deploy (الرابط بيفضل زي ما هو). التعديل صغير: لو الصفحة شغالة جوه التطبيق بتحفظ الملف في Downloads، ولو على المتصفح بتشتغل زي الأول.

## ملاحظات
- زر الطباعة (`printRpt`) في التقارير بيستخدم `window.open` ومش هيشتغل في التطبيق؛ استخدم تصدير CSV.
- التطبيق محتاج إنترنت (زي النسخة الأصلية). لو مفيش اتصال بتظهر شاشة "إعادة المحاولة".
- النسخة Debug موقّعة بمفتاح تجريبي وتنفع للاستخدام الداخلي. للنشر على Google Play لازم توقيع Release بمفتاحك الخاص.
- لو غيرت رابط النشر (Deployment جديد) لازم تحدّث `web_app_url` وتبني APK جديد، أو استخدم "Manage deployments ← Edit" عشان الرابط يفضل ثابت.

## 5) البصمة (جديد)
- **الدخول بالبصمة:** أول مرة تدخل بكلمة المرور داخل التطبيق هيسألك "تفعيل الدخول بالبصمة؟". بعد التفعيل بيظهر زرار "الدخول بالبصمة" في شاشة الدخول. كلمة المرور بتتخزن مشفرة بمفتاح محمي بالبصمة جوه الموبايل.
- **تسجيل الحضور/الانصراف:** كارت البصمة بيظهر في "My Profile" و"My Attendance". اختار حضور أو انصراف واضغط الأيقونة وضع إصبعك. التاريخ والوقت بيتسجلوا من السيرفر نفسه.
- الكارت وزرار البصمة بيظهروا **جوه التطبيق بس**، مش في المتصفح.
- لو غيرت البصمات المسجلة على الموبايل أو غيرت كلمة المرور، لازم تدخل بكلمة المرور وتفعّل البصمة من جديد.
- **مهم:** البصمة بتأكد إن صاحب الموبايل هو اللي بيضغط (أي بصمة مسجلة على الجهاز). مش بتربط الموظف ببصمته هو بالذات.

## 6) التحديث على موبايل عليه نسخة قديمة
احذف النسخة القديمة الأول ثم ثبّت الجديدة، لأن كل بناء على GitHub بيتوقع بمفتاح تجريبي مختلف.

## 7) تحديثات الإصدار 1.2
- شاشة بداية فيها لوجو SYSORA وبصمة متحركة (ملفات `app/src/main/assets/splash.html` و`logo.png`).
- زر الرجوع في الموبايل بيقفل النافذة المفتوحة، أو القائمة الجانبية، أو يرجع للصفحة السابقة. ولو مفيش رجوع، اضغط مرتين للخروج.
- لو الدخول بالبصمة مفعّل، شاشة البصمة بتظهر تلقائياً أول ما تظهر شاشة الدخول.
- شاشة الدخول: مقاسات مظبوطة للموبايل، وكل الأزرار والنصوص بتتغير مع اللغة.
- ملفات النظام اللي تتحدّث في Apps Script بقت خمسة: `AppScript.html` و`Pages.html` و`AdminPages.html` و`LoginPage.html` و`Styles.html`.

## 8) تحديثات الإصدار 1.3
- اللوجو بخلفية شفافة، والبصمة بقت بصمة كاملة بحركة (الخطوط بتتفتح من المركز وبتتحرك).
- شريط تحميل بنسبة مئوية تحت "Attendance & Leave"، والشاشة بتفضل لحد ما النظام يكون جاهز فعلاً.
- رسالة "أنشأ هذا التطبيق أحد مستخدمي برمجة تطبيقات Google" بتتخفى جوه التطبيق.
- تقرير "Overtime Days Review": الجدول اتحط جوه حاوية الجداول زي باقي التقارير (ملف `Pages.html`).
- لازم تحدّث `AppScript.html` و`Pages.html` في Apps Script عشان الشريط يوصل 100% والجدول يتظبط.
- لازم يفضل في `app/src/main/java/com/sysora/attendance/` ملف واحد بس اسمه `MainActivity.java`، وماتحطش فيه نسخ قديمة.
